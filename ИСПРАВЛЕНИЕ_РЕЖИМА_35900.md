# ИСПРАВЛЕНИЕ: OpenCL kernel self-test failed для режима 35900

## Проблема
Вы столкнулись с ошибкой:
```
* Device #1: ATTENTION! OpenCL kernel self-test failed.
Aborting session due to kernel self-test failure.
```

## Причина
Предыдущее исправление в PR #25 пыталось использовать `CONSTANT_AS` (константная память) для хранения предвычисленных точек эллиптической кривой secp256k1. Однако:

1. **Ограниченная константная память** — устройства OpenCL имеют только 64-96 КБ константной памяти
2. **Исчерпание памяти** — ваша видеокарта не смогла выделить достаточно константной памяти
3. **Некорректные результаты** — ядро работало неправильно, поэтому self-test не прошёл

## Решение
Вернулись к проверенному подходу `PRIVATE_AS`, который используется в других рабочих режимах (28501, 28505, 30901):

- Предвычисленные данные хранятся в **регистрах каждого потока** (приватная память)
- Нет ограничений по константной памяти
- Работает на **всех устройствах**: NVIDIA, AMD, Intel

## Что было исправлено

### 15 файлов ядер OpenCL
- Режим 35900 (Bitcoin P2PKH/Bech32/P2SH)
- Режим 35901 (Bitcoin Nested SegWit)
- Режим 35902 (Bitcoin Bech32 only)
- Режим 35903 (Bitcoin P2PKH compressed)
- Режим 35904 (Bitcoin P2PKH uncompressed)

Для каждого режима исправлены 3 варианта атаки: a0 (rules), a1 (combinator), a3 (brute-force/mask)

### Изменения в коде
1. Изменён `SECP256K1_TMPS_TYPE` с `CONSTANT_AS` на `PRIVATE_AS`
2. Добавлена локальная инициализация `preG` в каждой функции ядра:
   ```c
   secp256k1_t preG;
   set_precomputed_basepoint_g (&preG);
   ```
3. Обновлены все вызовы `point_mul_xy()` для использования `&preG`

## Технические детали

### Почему PRIVATE_AS лучше?

| Характеристика | CONSTANT_AS (PR #25) | PRIVATE_AS (это исправление) |
|----------------|----------------------|------------------------------|
| Размер памяти | 64-96 КБ **на всё устройство** | ~3 КБ **на поток** |
| Совместимость | Ограниченная | Универсальная |
| Производительность | Может быть быстрее | Стабильная |
| Надёжность | Непредсказуемая | Проверенная |

### Сравнение с другими режимами

Режимы, которые **работают** с PRIVATE_AS:
- 28501 (Bitcoin WIF)
- 28502 (Ethereum Keystore)
- 28505 (Ethereum wallet)
- 30901 (Blockchain wallet)

Теперь режимы 35900-35904 используют **тот же подход**.
