## 🔴 КРИТИЧЕСКИЕ ОШИБКИ

### 1. Ошибка распространения заимствования (Borrow Propagation Bug)

**Файл**: `OpenCL/inc_ecc_secp256k1.cl`  
**Строки**: 529-562  
**Функция**: `mod_512()`

**Проблема:**  
Алгоритм вычитания читает из уже измененного массива результатов, что приводит к неправильным вычислениям.

```c
// НЕПРАВИЛЬНО (текущий код):
r[0] = a[0] - r[0];
r[1] = a[1] - r[1];
// ...
if (r[1] > a[1]) r[0]--;  // r[0] уже изменен!
```

**Влияние:**  
Неправильные приватные ключи → неправильные адреса → **невозможность взлома правильных паролей**

**Решение:**  
Использовать временный массив для корректного распространения заимствования.

---

### 2. Переполнение при левом сдвиге (Left Shift Overflow)

**Файл**: `OpenCL/inc_ecc_secp256k1.cl`  
**Строки**: 1391-1412  
**Функция**: `point_add()`

**Проблема:**  
При удвоении t4 через левый сдвиг обработка переполнения неполная.

```c
// Проверяется MSB перед сдвигом, но carry не сохраняется
if (t4[7] & 0x80000000) { /* добавить omega */ }
```

**Влияние:**  
Повреждение операций сложения точек для граничных случаев → **неправильные публичные ключи**

**Решение:**  
Правильно захватывать и обрабатывать carry bit.

## ⚡ ВЫСОКОПРИОРИТЕТНЫЕ ОПТИМИЗАЦИИ

### 3. Перенос preG в константную память (+20% ускорения)

**Файлы**: Все 15 OpenCL ядер `m3590*_a*.cl`  
**Строки**: 37-39

**Проблема:**  
96 значений u32 (384 байта) загружаются для каждого work-item → ограничивает occupancy

**Решение:**
```c
CONSTANT_AS secp256k1_t preG_const = { /* 96 precomputed values */ };

KERNEL void m35900_mxx(...) {
    // Использовать &preG_const напрямую, без копирования на поток
    point_mul_xy(x, y, prv_key, &preG_const);
}
```

**Ожидаемый результат:**  
20-30% улучшение occupancy → 15-20% общее ускорение

---

### 4. Удаление избыточных копий координат (+10% ускорения)

**Файл**: `OpenCL/inc_ecc_secp256k1.cl`  
**Строки**: 1120-1244 (point_double), 1313-1451 (point_add)

**Проблема:**  
Каждая операция с точкой копирует все входные координаты в локальные переменные:

```c
u32 t1[8];
t1[0] = x[0];
t1[1] = x[1];
// ... 24 слова скопированы, 72 присваивания всего
```

**Решение:**  
Использовать указатели на входные данные напрямую, копировать только в конце при перезаписи результатов.

**Ожидаемый результат:**  
10-15% снижение давления на регистры + время выполнения
